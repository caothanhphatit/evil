# Image Generation Prompts

Use the generated `work/reference-sheet.png` as a style-reference image. It is
not an edit target. Generate one weapon per image, not a sheet containing many
weapons, once the five level-300 silhouettes have been approved.

## Shared prompt

```text
Use case: stylized-concept
Asset type: source concept for a 24x24 mobile-game weapon pixel sprite
Input image: style reference only; preserve its compact pixel-art language, hard clusters, limited palette, dark outline, transparent padding, and simple readable silhouette
Primary request: create [WEAPON NAME], a [CLASS WEAPON TYPE], with [THEME]
Composition: exactly one complete weapon, centered, generous padding, class-appropriate orientation matching the reference
Style: authentic low-resolution fantasy pixel art, designed to survive reconstruction on a 24x24 grid; 12-32 colors; hard pixel clusters; no smooth gradients
Backdrop: perfectly flat solid #00ff00 chroma-key background
Constraints: strong silhouette at thumbnail size; clear grip point; no cropped tip or handle; no antialiasing; no subpixel detail; no text; no person; no hands; no inventory frame; no rarity border; no star; no cast shadow; no floor; no reflection; no watermark
Avoid: photorealism, painterly illustration, 3D render, soft glow covering the silhouette, excessive particles, noisy micro-detail, multiple weapons
```

## First approval batch

### Berserker

```text
Create Stormbreaker Blade, a massive two-handed dark-steel blade with restrained lightning channels. Broad asymmetric silhouette, blade toward upper-left and grip toward lower-right. It must feel heavy without filling the entire canvas.
```

### Paladin

```text
Create Thunder Vow Hammer, a two-handed dark-steel warhammer with a strong architectural head and restrained lightning channels. Head toward upper-left and shaft toward lower-right. Balanced holy geometry, not a one-handed mace.
```

### Ranger

```text
Create Tempest Wing Bow, a nearly vertical dark-limbed recurved bow with a mild diagonal lean and restrained lightning channels. Preserve open negative space, readable string, grip, and both limbs.
```

### Sorcerer

```text
Create Stormcall Staff, a dark staff with a compact forked lightning focus. Staff runs lower-right to upper-left. Keep the magical focus small enough that the shaft remains readable.
```

### Dark Knight

```text
Create Nightstorm Glaive, a long dark-steel glaive with a sharp readable blade, narrow neck, shaft, and counterweight, plus restrained lightning channels. Run lower-right to upper-left.
```
